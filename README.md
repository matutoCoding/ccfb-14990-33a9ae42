# 犀皮漆髹饰推演台

浏览器内的犀皮漆工艺推演系统：参数化胎体 → 确定性起底 → 逐层髹涂（凸薄凹厚）→ 研磨磨显回放 → 纹样量化比对 → 可打印工艺单。纯 TypeScript + WebGL2 自写着色器，工艺档案存 IndexedDB，零运行时第三方依赖。

## 启动

```bash
pnpm install
pnpm dev        # 开发，默认 http://localhost:5180
pnpm build      # 类型检查 + 生产构建
pnpm test       # 确定性与层厚模型测试（Node 内置 runner）
pnpm typecheck  # 严格类型检查
```

## 六个页面

| 路由 | 能力 |
| --- | --- |
| 作品列表 | 按订单建档、删除、切换；首次启动预置 4 个样例 |
| 胎体与起底 | 盘/盒/碗参数化器型、OBJ 导入栅格化；四种起底布点（抖动网格、手指捺痕、麻籽撒点、平行棱脊） |
| 髹漆层 | 逐层颜色/名义厚度/收缩率/流薄系数/阴干天数，右侧显示 GPU 实算层厚均值与极值 |
| 打磨推演 | 俯视走刀实时磨显、平台磨、磨具压力硬度调节、磨穿标红、薄漆热力图、逐磨次回放定位 |
| 纹样比对 | 参考照片（IndexedDB 存图）与推演抓帧并排，k-means 色块占比 + Sobel 纹路/圈纹密度对比评分 |
| 工艺单 | 完整髹饰参数与打磨顺序，浏览器打印或另存 PDF |

## 确定性设计（同参数两次结果完全一致）

1. **随机源唯一**：所有布点走 `mulberry32(hashSeed(参数串))`，无 `Math.random` 进入推演链路
2. **走刀定长重采样**：指针路径按固定 4mm 步长重采样，不同帧率/设备产生同一触点序列
3. **GPU 纯函数 pass**：沉积、研磨都是固定网格上的浮点纹理运算，无时间相关量
4. **回放即重算**：切换磨次时从最后一层顶面开始，按操作记录逐 pass 重放

## 层厚物理模型

每层有效名义厚度 = 名义厚度 ×（1 − 收缩率），逐像素再乘曲率流挂系数：

```
lap      = 邻域高度和 − 4×当前高度     // 凸顶为负、凹处为正
k_norm   = clamp(-lap / (3·名义), -1, 1)
slope    = 相邻高度梯度
factor   = clamp(1 − flow·k_norm − 0.3·flow·slope_norm, 0.35, 1.9)
实际厚度  = 名义 × factor
```

凸顶 `k_norm>0` 系数小于 1 流薄，凹处系数大于 1 积厚。CPU 参考实现见 `tests/deposit_model.test.ts`，与 `DEPOSIT_FS` 着色器公式一一对应。

## 性能

- 默认推演网格 1024×1024 R32F，层高度用 `TEXTURE_2D_ARRAY`（最多 16 层）
- 渲染循环脏标记驱动，空闲不耗 GPU；统计读数先降采样到 64×64 再回读
- 研磨触点按 128 个一组分块传入 uniform，单次 pass 全屏并行
- 起底高度场 1024 网格 CPU 构建约 350ms（见测试基线），参数调节走 220ms 防抖重建

## 工艺约束与边界

- OBJ 导入按俯视正交投影取顶高栅格化，适合规整器型；深腹异形建议用参数化碗型
- 磨穿判定阈值 0.0015mm，薄漆热力阈值可在打磨页调节（默认 0.25mm）
- 单触点切深 = 压力 × 硬度 × 0.06mm，为经验系数，可在 `GRIND_FS` 统一调整
